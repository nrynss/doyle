Every memory an agent keeps rests on an external source like an API contract, a COBOL paragraph, or an operator console screen. When that source changes, the memory goes stale and the agent keeps acting on it.

Doyle is truth maintenance for agent memory. It records what each memory cites, flags memories when sources change or differential runs fail, and asks a Meta model to propose a correction.

A Muse Code hook holds the agent at the step where a stale belief would do damage. Once a human reviewer signs off, Doyle writes the correction back to Muse Code built-in memory and Lambo.

## The problem

A careful agent may probe past a stale memory in one session, but it leaves the wrong belief untouched in storage for the next session.

## The two stories

- **The Quiet Migration:** A veterinary clinic API adds pagination at 100 records while agent memory still says one call returns all 4,812 patients.
- **The Billing Cutover:** A COBOL billing batch port and console retirement face a planted fee bug, a record layout change, and a removed confirmation screen.
